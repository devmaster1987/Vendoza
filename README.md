# 🛒 Vendoza - Modern E-Commerce Marketplace

![Vendoza Banner](assets/images/banner.png)

## 📌 About The Project

**Vendoza** is a modern e-commerce marketplace inspired by platforms like **Amazon and Daraz**.

The goal of this project is to build a complete online shopping experience where users can browse products, search items, manage their cart, save favorites, and complete a checkout flow.

This is **Version 1**, built using pure frontend technologies:

- HTML5
- CSS3
- JavaScript

The project focuses on creating a professional, responsive, and scalable e-commerce foundation that can later be upgraded into a full-stack marketplace.

# 🚀 Getting Started

Follow these steps to run Vendoza locally.

## 1. Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/vendoza.git
```

## 2. Open Project

```bash
cd vendoza
```

## 3. Run Website

No installation required.

Simply open:

```
index.html
```

in your browser.
