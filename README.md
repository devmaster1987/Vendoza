# 🛒 Vendoza - Modern E-Commerce Marketplace

![Vendoza Banner](assets/images/banner.png)


# 📌 About The Project

**Vendoza** is a modern e-commerce marketplace inspired by platforms like **Amazon and Daraz**.

The goal of this project is to create a complete online shopping experience where users can browse products, search items, manage their cart, save favorites, place orders, and manage their accounts.

Vendoza is built as a scalable marketplace foundation with both:

- Customer shopping experience
- Admin management system


Current version uses pure frontend technologies and browser storage for data management.
